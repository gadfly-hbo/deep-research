## 1. 产品定位

独立深度研究(Deep Research)是一个可以单独运行、独立使用的专业研究工具,面向品牌、行业等研究任务,围绕用户提出的问题,自动制定研究计划、获取和分析资料、核查证据、形成研究判断,并交付可追溯的研究成果。第一期聚焦品牌研究与行业研究两个模块,后续逐步扩展到商圈研究、消费者研究、人文研究等,并考虑与 JuanerAI 的打通。

## 2. 产品目标

- 提供专业、可验证的研究结论
- 降低高质量研究的时间与人力成本
- 支持多场景研究能力的持续扩展
- 形成可长期积累的研究资产
- 未来与 JuanerAI 打通,成为其研究能力模块

## 3. 核心价值

- 专业可靠:证据可追溯,不编造结论
- 高效智能:多智能体协作,自动完成复杂研究流程
- 灵活通用:支持多类研究场景与自定义配置
- 可持续扩展:模块化设计,便于后续与 JuanerAI 集成

## 4. 主要功能

- 研究项目管理:创建与管理研究项目;设置研究目标与范围;支持历史项目回溯
- 智能研究流程:问题拆解与计划制定;资料获取与证据管理;分析撰写与评审修复;自动补证与迭代优化
- 专业研究模块:品牌研究模块(第一期);行业研究模块(第一期);后续扩展:商圈 / 消费者 / 人文研究等
- 成果交付与复用:研究报告(Markdown / HTML);证据与来源清单;研究限制与未解决问题;项目版本管理与复用

## 5. 研究流程(通用)

1. 需求输入:明确研究目标、范围与资料
2. 计划制定:问题拆解、生成研究计划
3. 资料获取:多渠道搜索、资料解析与证据管理
4. 分析撰写:基于证据分析生成报告草稿
5. 评审修复:质量检查、问题修复与补证
6. 交付成果:输出报告与证据清单、支持后续复用

## 6. 第一期实施范围

第一期(v1.0)—— 独立可用的品牌研究与行业研究。

**必须实现:**

- 独立工作台(创建任务、查看进度、管理项目、导出成果)
- 通用研究核心(问题拆解、计划、采证、分析、评审、补证)
- 品牌研究模块(完整的研究方法、模版与质量检查)
- 行业研究模块(完整的研究方法、模版与质量检查)
- 证据追溯与研究交付(报告 + 来源清单 + 研究限制)
- 项目保存与版本管理
- 在不依赖 JuanerAI 的环境中独立运行

**明确不包含(后续考虑):**

- 商圈研究、消费者研究、人文研究
- 与 JuanerAI 的集成与数据打通
- 账号体系、支付系统、多租户平台
- 复杂的插件市场与生态
- 消费者问卷投放、访谈招募等专项平台
- 企业内部知识库与业务系统对接

## 7. 后续规划

- 第二期:研究能力扩展 —— 商圈研究模块、消费者研究模块、人文研究模块、更多行业与品牌场景优化
- 第三期:生态与集成 —— 与 JuanerAI 打通、研究成果进入分析与策略流程、插件与数据源生态、团队协作与权限管理
- 长期愿景:成为企业与个人的通用研究基础设施;支持更广泛的知识工作场景;持续提升研究深度与专业性

## 8. 成功标准(第一期)

- 品牌研究模块可以独立完成一项真实任务,结论有据可查,未验证内容明确标注。
- 行业研究模块可以独立完成一项真实任务,数据口径清晰,冲突来源得到解释。
- 在不安装、不启动、不连接 JuanerAI 的情况下,可以完成研究全流程。
- 支持保存项目、重新打开、补充证据、重新评审和导出成果。
- 资料不足时能够有限交付,而不是编造完整答案。

## 9. 第一期实施边界与目标架构(页 1)

第一期:品牌研究 × 行业研究 / 独立运行 · 证据可追溯 · 后续再集成。
边界说明:双模块分别可用、分别验收;共享同一套研究能力。

### 9.1 分层架构

(实线 = 一期范围;虚线 = 后续范围。分层表示职责与依赖边界;首期可采用模块化单体,不要求部署为多个微服务。)

1. **独立工作台**(浏览器 + 本地服务;单用户 · 独立启动):创建任务 · 计划确认 · 研究进度 · 证据抽屉 · 成果导出
2. **品牌研究模块**(一期正式交付):品牌定位 · 产品价格 · 渠道 · 竞品;产出:品牌档案 / 对比表 / 机会、风险与假设
3. **行业研究模块**(一期正式交付):行业边界 · 规模口径 · 产业链 · 竞争;产出:市场口径表 / 行业结构 / 趋势与风险
4. **研究应用服务**:项目 · 任务状态 · 权限 · 版本 · 预算;通用契约:ResearchRequest / ResearchRun / ResearchResultBundle
5. **通用研究核心**(四类职责:主控 / 研究 / 写作 / 评审):
   问题计划(范围 · 问题 · 方法)→ 采证阅读(搜索 · 原文 · 定位)→ 证据分析(口径 · 主张 · 冲突)→ 报告草稿(发现 · 依据 · 限制)→ 评审修复(核查 · 修正 · 复核)→ 发布成果(正常 / 有限交付);
   回环:缺口补证 · 反例检查 · 受影响内容复核;
   约束:资料不足或预算到达上限时,披露限制,不编造完整答案
6. **工具适配层**:模型接入 · 网络搜索 · 网页读取 · 文本 / PDF 解析 · 受控数值计算
7. **本地项目存储**(元数据 + 项目文件;不依赖外部业务底座):资料快照 · 证据与主张 · 运行检查点 · 报告与版本
8. **可追溯研究成果**:Markdown / HTML / 结构化成果包;结论 + 依据 + 限制 + 版本

### 9.2 横向质量与运行控制(贯穿全部研究阶段)

- 01 引用与证据:原文定位 · 事实与推断 · 关键结论可追溯
- 02 口径与逻辑:对象 · 时间 · 单位 · 比较边界与反证
- 03 发布门禁:高风险问题处理 · 修复后重新核查
- 04 运行可靠性:检查点 · 取消 · 恢复 · 失败不冒充完成
- 05 资源预算:受控并行 · 调用上限 · 停止条件明确
- 06 数据与工具权限:外发授权 · 密钥保护 · 来源内容不可信
- 07 版本与审计:配置 · 证据 · 报告 · 实际执行记录

原则:执行完成 ≠ 证据充分;允许有依据的有限交付。

### 9.3 后续扩展(不纳入第一期)

- 更多研究类型与组合:消费者研究 · 人文研究 · 商圈研究 · 跨类型研究;通过研究配置、方法与验证器逐步扩展
- JuanerAI 未来作为使用方:通过请求 / 状态 / 成果契约适配;一期不建设专属接缝,不依赖其数据库与语义底座

## 10. 产品架构图(第一期,页 2)

独立运行,模块化设计,支持未来扩展。

- **用户层**(独立使用):深度研究工作台(Web 界面)—— 创建研究项目 · 配置研究需求 · 查看执行进度 · 浏览证据资料 · 阅读与导出报告 · 项目管理
- **应用服务层**(产品功能):研究任务服务 —— 任务管理 · 状态跟踪 · 资源调度 · 失败处理 · 结果输出 · 项目版本管理
- **研究核心层**(通用能力):
  - 研究引擎(多智能体协作):需求澄清与问题拆解 → 研究计划制定 → 资料获取与证据管理 → 分析与撰写 → 质量评审与修复 → 补证与迭代 → 成果组织与交付
  - 研究模块配置(第一期):品牌研究模块(研究方法与问题框架 · 来源策略与验证规则 · 报告模板与结构化字段 · 专项质量检查);行业研究模块(同四件套);后续扩展:商圈 / 消费者 / 人文 / 更多模块
- **工具与存储层**(基础能力):
  - 模型与推理服务:大语言模型(如 MiniMax / Kimi / GLM 等)
  - 信息获取与解析:搜索服务(如 MiniMax WebSearch);网页读取 / 文档解析 / 数据清洗
  - 数据存储:项目元数据 · 资料与证据 · 报告与版本
  - 基础设施:本地部署 / 云部署 · 日志与监控 · 配置管理
