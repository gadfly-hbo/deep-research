## 3. Affordances(控件 · 键盘 · 焦点 · 可达性)

**控件**(全部复用 `sb-*` 形态语言,新增件遵循 DESIGN.md 控件约定,不引组件库):
- 类型「＋」:16px 方形 ghost 微按钮,`aria-label="新建品牌研究项目/新建行业研究项目"`。
- 项目行主区:`div role="button" tabindex=0`(循现状 Sidebar.tsx:37-38 先例),内含 caret(aria-hidden,点击切换)+ 名称;悬停「＋」「⋯」收进 `.sb-actions`,行 hover 或 **focus-within** 时显现(键盘可达)。
- 任务行主区:原生 `<button>`(循现状 run 行先例),`title="查看该项目当前调查流"`。
- 菜单:白卡浮层,`--radius-sm` + `--shadow-float`,`role="menu"`,项 `role="menuitem"`;来源二通道:悬停「⋯」与行右键(D4「右键/悬停菜单」)。
- 内联改名:行内 `<input>`(等宽场景不用)+ 行下提示行「Enter 保存 · Esc 取消 · 留空恢复默认」+ 计数 `n / 60`(tabular-nums);>60 字显示红色内联错误并阻断保存。不设 maxlength 硬截断(允许粘贴后看到错误,与服务端 400 对齐)。
- 状态:点(`dot-*` 四色,aria-hidden)+ 状态词(`sb-meta`)双通道;running 静态琥珀点,不加动画(不发明规格外视觉)。

**键盘与焦点序**(Tab 序 = 视觉序):⌘K 搜索 → 外部情报库 → 顶部条件按钮 → 品牌研究「＋」→ 项目行主区 →(该行)「＋」「⋯」→ 任务行主区 →(该行)「⋯」→ …… → 行业研究「＋」→ …… → 已归档节头 → 设置。快捷键:Enter/Space 激活行;→ / ← 仅项目行展开/收起;Esc 关闭菜单或取消编辑(焦点返还原行);菜单内 Tab/Shift+Tab 移动,不循环出界(Esc 必须可达)。编辑器 Enter 显式提交、blur 取消(防止误触空=清除)。焦点环:3px `rgba(232,100,58,.28)` + 2px offset(DESIGN.md)。

**aria**:`nav aria-label="项目与任务导航"`(§8-diff1);节头计数、状态词为文本;骨架期树容器 `aria-busy="true"` + 视觉隐藏「加载中」;toast `role="status"`;caret 展开态由项目主区 `aria-expanded` 承载;任务行按钮 `aria-current` 于当前任务。

## 5. Negative cases(禁止路径)

- **N1** 版本子树不回归:侧栏任何位置不出现 vN 行 / 版本 caret / 版本徽;发布页 `?v=` 入口不受影响(D7)。
- **N2** 归档区无任务子树、无「＋」、无 caret(G1-7);仅行导航 + 重命名菜单。
- **N3** running 任务不可改名:菜单项禁用;提交层 409 兜底 + reload(G1-5)。
- **N4** 树内「＋」在守卫时禁用(running/awaiting 存在),title=守卫文案;顶部按钮同判据同禁用(D6)。
- **N5** 不新造导航标签:节头仅 品牌研究 / 行业研究 / 已归档;顶区仅 搜索 / 外部情报库 / 条件新建;底部仅 设置。
- **N6** 名称不落非法值:空串/全空白 = 清除回退(null 语义),不写空串;修剪后 >60 → 400,不静默截断(G1-4)。
- **N7** 侧栏不承载运行控制:取消/恢复/确认门操作仍在既有页面位置,树行点击只导航。
- **N8** 不建 per-run 独立路由,不做历史调查流切换(Out of Scope)。
- **N9** rerun/followup 不弹命名输入:后缀自动命名,发起路径零改动(D5/G1-6)。
- **N10** 任务列表不做「最近 N」截断、不加「显示更多」;全量 mtime 倒序(D1/D7/G1-2)。
- **N11** 不做多选/拖拽/树搜索(proposal 出界)。
- **N12** 原型不接真实 API、不改 run 执行/恢复/门禁语义;一切数据为合成样例(§7)。

## 7. Data fidelity

- 原型数据(项目「安克品牌研究」、未命名项目、储能行业摸底、归档样例及其任务)为**合成样例**,服务端真实数据在本任务上下文不可访问;requestId、时间戳、状态均为演示构造。
- 原型不发起任何网络请求;轮询(30s/2.5s)、reload、409/400 均以按钮「注入竞态」与状态翻转演示,行为边界以本契约 §2 为准。
- 视觉 token 逐值取自 `ui/styles.css` :root 与 sb-* 段(色板/圆角/字号/焦点环/toast);品牌 logo 图(契约冻结 SHA)不以位图内嵌,以占位块示意,文案与版式循 TopBar.tsx 现状。
- 侧栏宽度取真实 token 248px(见 §8-diff5);主区/Inspector/statusbar 为最低保真 mock,仅佐证整窗上下文与「模拟路由」。
